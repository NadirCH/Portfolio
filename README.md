# Nadir Chabani — Creative Front-End Developer & UI/UX Designer Portfolio

Modern, high-performance portfolio website inspired by Obys Agency aesthetics. Built with **React 18**, **Vite**, **GSAP**, and **Lenis** smooth scrolling.

🌐 **Live Website**: [https://nadirch.github.io/Portfolio/](https://nadirch.github.io/Portfolio/)

---

## ⚡ Tech Stack

- **React 18** — Component-driven interface
- **Vite 5** — Lightning-fast build tooling and HMR
- **GSAP (GreenSock)** — Editorial kinetic typography, reveals, magnetic buttons, and timeline orchestration
- **Lenis** — Weightless, smooth scrolling
- **Lucide Icons** — Lightweight SVG iconography

---

## 🚀 Local Development

```bash
# Clone the repository
git clone https://github.com/NadirCH/Portfolio.git

# Navigate into project directory
cd Portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

---

## 📦 Production Build

```bash
npm run build
npm run preview
```
